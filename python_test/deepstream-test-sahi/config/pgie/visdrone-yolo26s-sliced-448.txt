# PGIE config — YOLO26s (VisDrone, sliced 448) for the DeepStream-SAHI pipeline.
#
# YOLO26 is end-to-end / NMS-free: the ONNX emits a single output tensor
#   output0 = [N, 6]  ->  x1, y1, x2, y2, conf, class_id   (already post-NMS)
# so we use the NvDsInferYoloE2E parser (from libnvds_infer_yolo.so) and let
# nvsahipostprocess merge detections across tiles (GreedyNMM).
#
# Tensors are fed by nvsahipreprocess (see config/preprocess/preprocess_448.txt,
# processing 448x448, RGB, /255), so the scaling keys below are only used if this
# GIE is run standalone.
#
# Place the model here (LFS copy from the model package), or edit onnx-file:
#   cp model_zoo/visdrone_yolo26/04_models/yolo26s/best.onnx \
#      python_test/deepstream-test-sahi/models/yolo26s-visdrone-sliced-448.onnx
################################################################################
